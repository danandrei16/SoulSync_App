Overview

This is a Tinder-inspired application built using React, Node.js, and Firebase. The app allows users to connect with others based on their preferences, offering features such as swipe functionalities, real-time messaging, and notifications. Users can edit their profiles to customize their experience.

Features


* Swipe Functionalities:
Swipe right to like and left to pass on user profiles. Matches occur when both users swipe right.

* Real-Time Messaging:
Chat with your matches instantly using real-time messaging powered by Firebase.

* Real-Time Notifications:
Get notified instantly for new matches or incoming messages.

* Profile Customization:
Edit your profile, including preferences, bio, and pictures, to personalize your experience.

* Preference-Based Matches:
See people tailored to your preferences such as age, location, or interests.
